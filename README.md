# Zoom Bot Console

Сервис для автоматизации лекций/вебинаров в Zoom: бот на базе Ubuntu-VM входит в
конференцию по расписанию, при необходимости запускает запись, ведёт простую
модерацию чата (спам, нецензурные слова) и отдаёт живой просмотр происходящего
(скриншоты экрана) в веб-интерфейс.

> **Статус:** этап 1 из 7 — базовый каркас. Дорожная карта ниже.

## Архитектура

```
web (FastAPI)   — веб-интерфейс, расписание, REST/WS, живой просмотр
scheduler       — по времени запускает вход в конференцию и запись
zoom-api        — Server-to-Server OAuth: митинги, ZAK хоста, запись
bot-worker      — Ubuntu + Xvfb + Zoom-клиент: вход, старт, запись, скриншоты, чат
db (Postgres)   — расписание, логи, события модерации
redis           — брокер задач планировщика
```

**Подход к боту:** официальный десктоп-клиент Zoom на Ubuntu под виртуальным
дисплеем (Xvfb). Вход в митинг через URL-схему `zoommtg://`, запись экрана через
`ffmpeg`, скриншоты с того же дисплея. Чат-модерация — слой `ChatReader`
(основной путь AT-SPI, запасной OCR/Tesseract).

## Быстрый старт

```bash
cp .env.example .env       # заполнить пароли/секреты
docker compose up --build
```

- Веб-интерфейс: <http://localhost:8000>
- Health: <http://localhost:8000/health>

## Требования

- Docker + Docker Compose
- Zoom-аккаунт с доступом к <https://marketplace.zoom.us> (для этапа 3)
- Отдельный тех-аккаунт Zoom для бота (для этапа 5)

## Замечания по правилам

Запись и модерация требуют, чтобы бот был host/co-host, а участников необходимо
уведомлять о записи (Zoom обычно показывает баннер автоматически). Использовать
только на своих мероприятиях и в рамках Zoom Terms of Service.
